# Predictive Analytics using Historical Sales Data

This project predicts future sales trends using historical sales data and Linear Regression.

## Tools Used
- Python
- Pandas
- Matplotlib
- Scikit-learn

## Machine Learning Model
Linear Regression

## Process
1. Loaded historical sales dataset
2. Cleaned and preprocessed data
3. Grouped monthly sales
4. Applied Linear Regression
5. Visualized actual and predicted sales

## Output
The model forecasts sales trends based on historical data patterns.

Predictive analytics helps businesses forecast future performance and make data-driven decisions.
